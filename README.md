# 📱 Mi Agenda de Contactos

Una agenda simple creada en Python para practicar funciones, diccionarios y bucles.

## ✨ ¿Qué puedes hacer?
- Añadir, buscar, editar y eliminar contactos.
- Ver la lista completa de contactos guardados.

## 🛠️ Cómo ejecutarlo
1. Asegúrate de tener Python instalado.
2. Descarga el archivo `agenda.py`.
3. Ejecútalo con: `python agenda.py
